# interstellar_Boost

Бот для [interstellar.dachain.io](https://interstellar.dachain.io): регистрирует кошельки по реферальным кодам, проводит их через гейт с launch-кодами, делает ежедневный чек-ин и квесты. Работает только запросами, без браузера; капча Cap.js решается локально в Node.js. Отдельно `game.py` играет в Chip Entropico (`/game/`).

Запросы идут через [curl_cffi](https://github.com/lexiforest/curl_cffi) с TLS/HTTP2-отпечатком Chrome и порядком заголовков как у `fetch()` в Chrome. У каждого кошелька свой браузер (Chrome или Edge на Windows, актуальная версия, свой язык), он вычисляется из адреса и не меняется между запусками.

## Что делает

**`MODE = 1`** — для каждого кошелька из `Wallet.txt` без пометки `done`:
1. привязывает реф-код из `Ref.txt` (каждому коду — случайно от `REGS_MIN` до `REGS_MAX` кошельков);
2. проходит гейт с launch-кодом из `code.txt`;
3. делает чек-ин и квесты (Follow X, Discord, Telegram, сайт, первый сундук);
4. забирает 3 своих launch-кода кошелька в `code.txt`;
5. дописывает `,done` в строку кошелька.

Кошельки с `done` в этом режиме только делают чек-ин.

**`MODE = 2`** — только чек-ин у кошельков с `done`.

Сессия кошелька сохраняется в его строке и переиспользуется. Если она истекла, бот входит заново по ключу. Мёртвый прокси заменяется следующим из `Proxy.txt`.

## Установка

Нужны **Python 3.10+** и **Node.js 22.13+** (на нём решается капча, npm-пакеты не нужны).

Windows: запустите `install.bat`. Или вручную:

```
python -m venv .venv
.venv\Scripts\python.exe -m pip install -r requirements.txt
```

## Файлы данных

Скопируйте примеры и заполните своими данными:

| Пример | Рабочий файл | Что внутри |
|---|---|---|
| `Wallet.example.txt` | `Wallet.txt` | кошельки, по одному на строку (обязателен) |
| `code.example.txt` | `code.txt` | launch-коды для гейта (нужны в `MODE = 1`) |
| `Ref.example.txt` | `Ref.txt` | реф-коды для привязки (необязателен) |
| `Proxy.example.txt` | `Proxy.txt` | запасные прокси, по одному на строку (необязателен) |

Форматы прокси (в `Proxy.txt` и в строках кошельков; можно смешивать): `user:pass@host:port`, `host:port:user:pass`, `user:pass:host:port`, `host:port`, с приставкой `http://` или без неё. SOCKS — с приставкой `socks5://`. Прокси, взятый из `Proxy.txt`, удаляется оттуда и записывается в строку кошелька.

Строка `Wallet.txt`: `seed,derivation path,private key,address,proxy[,session][,done]`. Поля определяются по виду, порядок неважен. Достаточно одной сид-фразы: ключ и адрес вычисляются из неё, прокси берётся из `Proxy.txt` и записывается в строку.

Рабочие файлы перечислены в `.gitignore` и в репозиторий не попадают. **Никогда не публикуйте `Wallet.txt`**: сид-фраза и приватный ключ дают полный доступ к кошельку.

## Настройки

В начале `Boost.py`:

| Переменная | Что значит |
|---|---|
| `MODE` | `1` — регистрация + чек-ин, `2` — только чек-ин |
| `THREADS` | сколько кошельков обрабатывать одновременно |
| `REGS_MIN`, `REGS_MAX` | сколько кошельков привязать к одному реф-коду |
| `CAPTCHA_RETRIES` | повторы при `CAPTCHA_FAILED` |

Общие настройки (таймауты, капча, прокси) — в `config.py`.

## Игра Chip Entropico — `game.py`

Планировщик: у каждого аккаунта своё время следующего захода, оно хранится в `game_schedule.json`, так что после перезапуска бот продолжает с того же места. Заход в аккаунт:
1. клейм кэша за `GAME_CLAIM_BEFORE_FULL_MIN` минут до заполнения (кэш вмещает 2 часа добычи);
2. испытания: Bus Guardian, Private Key, Firewall, Attack (Attack — только при `GAME_ATTACK = 1`);
3. апгрейды, пока хватает QE: чип до `GAME_ENTROPY_AT_CHIP`, потом entropy-модуль до максимума, потом чип до максимума;
4. расчёт следующего захода: когда хватит на апгрейд, подойдёт клейм или закончится кулдаун.

Поток занят только на время захода (секунды), ожидание идёт в расписании. `GAME_THREADS` — сколько заходов идёт одновременно; кому пора, берутся по очереди, самые просроченные первыми. Когда всё прокачано, аккаунт заходит только за клеймом. Бот работает, пока его не остановить (Ctrl+C).

Откуда брать аккаунты — `GAME_SOURCE` в `config.py`: `1` — `Accounts.txt`, `2` — `Boost.txt`, `3` — `Wallet.txt` (только кошельки с `done`). Остальные настройки игры — переменные `GAME_*` в `config.py`.

Из папки проекта:
